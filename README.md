# OpenAirymax 开源极境  

> 构建群体智能的基石  

**OpenAirymax 开源极境**是专注于 AI Agent 操作系统的开源组织。  

- 组织使命：打造完整的操作系统生态，从内核机制到应用平台，为多智能体协同、自主进化、内在安全提供解决方案。  
- 核心项目：[AgentOS智能体操作系统](AgentOS/)   
- 社区参与：我们欢迎所有形式的贡献，详细方式请参阅 [AgentOS 贡献指南](https://atomgit.com/openairymax/agentos/-/blob/main/CONTRIBUTING.md)。  
- 许可证：OpenAirymax 组织下项目默认采用 **Apache License 2.0**，除非另有说明。  
- 主平台：**AtomGit**: [https://atomgit.com/openairymax/agentos](https://atomgit.com/openairymax/agentos)
