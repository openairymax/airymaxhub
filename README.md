# Airymax   

OpenAirymax 开源极境
> AI Agent Runtime Platform Engineering  

开源极境是一个专注于**智能体运行底座工程化平台**的开源组织。  

## 项目结构  

```
airymaxhub/
├── agentrt/         # 核心运行底座（继承原 AgentOS & AgentRT 历史）
├── sdk/             # 多语言SDK
├── ecosystem/       # 工程生态系统
├── products/        # 面向用户制品
├── devtools/        # 开发工具
├── docs/            # 项目文档
└── docs-closed/     # 项目管理文档（闭源）
```
